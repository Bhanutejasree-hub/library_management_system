# 📚 Library Management System

##  About the Project

The **Library Management System** is a mini SQL project developed using **MySQL**. It is used to store and manage information about library members, books, suppliers, fines, and book issue/return details.

##  Technologies Used

* MySQL
* MySQL Workbench
* SQL

##  Tables Used

The database contains 5 tables:

* `lms_members` – Stores member details
* `lms_suppliers_details` – Stores supplier details
* `lms_book_details` – Stores book information
* `lms_fine_details` – Stores fine details
* `lms_book_issue` – Stores book issue and return details

The tables are connected using **Primary Keys and Foreign Keys**.

## SQL Concepts Used

* Database and table creation
* Primary Key
* Foreign Key
* INSERT
* SELECT
* WHERE
* JOIN
* GROUP BY
* COUNT()
* LIKE
* Date filtering

## 📊 Project Work

* Created the library database and tables
* Inserted sample records
* Created relationships between tables
* Executed SQL queries to retrieve required information
* Performed filtering, joins, grouping, and aggregate operations
